Instructions for PC/Windows (not SnapDragon processors)

If you have a MacBook/Apple computer, skip to the next section of these instructions.

Please complete the following steps before completing anything else in the course.

  1. Download the latest version of the following software to your PC/Mac.
    • VirtualBox Base Package (run it as administrator if you get an error)
    • VirtualBox Extension
    • Ubuntu Desktop - The latest LTS version of Ubuntu Desktop is best. Sometimes newer versions may have issues at first. You may need to edit the settings of the Virtual Machine to use a different display driver. If you have troubles and want and older one that is more likely to work, download the 20.04 version.
  2. Install the following software:
    • VirtualBox Platform Package
    • VirtualBox Extension Pack
  3. These settings:
    1. Memory: 4 GB (4096 MB) (Ubuntu Desktop Requirement)
    2. Disk: 25 GB (25000 MB) (Ubuntu Desktop recommended)
    3. Install Ubuntu Desktop
  4. Add Copy/Paste Functionality
    1. Start the virtual machine.
    2. Once the guest OS has fully booted and you are logged in, click on the Devices menu in the running VM's window top menu bar.
    3. Select Insert Guest Additions CD image.... This action virtually inserts an installation ISO file into the VM's CD drive.
    4. Inside the guest VM, an installation prompt may appear automatically. If so, follow the prompts to install, accepting default options.
    5. If the installation doesn't start automatically (common in some Linux guests), navigate to "This PC" or "Computer" within the guest file explorer, open the virtual CD drive (labeled VBox_GAs_...), and run the installer file (e.g., VBoxWindowsAdditions.exe for Windows guests, or the appropriate script for Linux/macOS).
    6. Follow the installation steps. The screen might flicker briefly during driver installation (this is normal).
    7. Once the installation is complete, restart the virtual machine for the changes to take full effect.
  • Open the VirtualBox Manager application on your host PC.
  • Select the desired virtual machine from the list.
  • Click the Settings (yellow cog icon) button in the toolbar.
  • In the Settings dialog box, select the General category in the left pane.
  • Go to the Advanced tab on the right.
  • Find the Shared Clipboard dropdown menu and select Bidirectional.
  • (Optional) For easier file transfers, also set the Drag'n'Drop dropdown to Bidirectional.
  • Click OK to save the changes and close the settings.

Instructions for Mac/Apple (not Apple Neo laptops)

If you have a computer with an Apple CPU (Specifically the M1, M2, M3, M4, etc. chip), follow the instructions below. If you have an Apple CPU with Intel, you could try the instructions below but you may need modify some settings or use the Virtual Box Install Method at the bottom of the page.

  1. Verify that your MAC has an Apple CPU (Or M1, M2, M3, M4, etc. chip).
    • Follow the instructions in the following document to complete this step: Mac computers with Apple silicon.
  2. Download and install Virtual Box or UTM. Pick ONE.
    • (Recommended) VIRTUAL BOX: Find the Download for your chip type (macOS / Apple Silicon hosts for M Chips or Intel hosts for Intel Chips): https://www.virtualbox.org/wiki/Downloads
    • (Not required but another option if Virtual Box doesn't work) UTM: Click on "Download" at the following link to install the software: GetUTM.
  3. Download Ubuntu Desktop for ARM Architecture (unless you have an old Intel CPU).
    • Ubuntu Desktop - The latest LTS version of Ubuntu Desktop is best. Sometimes newer versions may have issues at first. You may need to edit the settings of the Virtual Machine to use a different display driver. If you have troubles and want and older one that is more likely to work, download the 20.04 version.
  4. Create a VM on Virtual box or UTM and install Ubuntu.
  5. Follow steps on screen for the installation with the following modifications:
    1. Memory: 4 GB (4096 MB) (Ubuntu Desktop Requirement)
    2. Disk: 25 GB (25000 MB) (Ubuntu Desktop recommended)
    3. Install Ubuntu Desktop
  6. Add Copy Paste Virtual Box (Highly Recommended):

    Mount the Guest additions CD: Click on “Devices” menu > Insert Guest Additions CD image.

    Open the terminal in your VM and type these commands:

    cd /media
    ls
    cd user
    ls
    cd VBox_GAs_7.1.8/
    ls
    ./autorun.sh
    sudo apt update
    sudo apt install bzip2 tar
    sudo apt install gcc make perl
    ./autorun.sh
    sudo reboot

    On the Virtual Box Manager application, click on “settings” on the VM selected. Click on “Advanced” tab and under “Shared Clipboard” click “Bidirectional”
  7. Enable Copy Paste Virtual Box:
    • Open the VirtualBox Manager application on your host PC.
    • Select the desired virtual machine from the list.
    • Click the Settings (yellow cog icon) button in the toolbar.
    • In the Settings dialog box, select the General category in the left pane.
    • Go to the Advanced tab on the right.
    • Find the Shared Clipboard dropdown menu and select Bidirectional.
    • (Optional) For easier file transfers, also set the Drag'n'Drop dropdown to Bidirectional.
    • Click OK to save the changes and close the settings.

Instructions for Neo and SnapDragon Processors

If you have an Apple Neo laptop or a SnapDragon processor, Virtual Box or UTM may not work as expected.

  1. Verify that you have a SnapDragon processor or Apple Neo laptop (ask AI if needed).
  2. Download and install Virtual Box or UTM from the Windows or Mac instructions above, but know that it might not work. Don't spend too much time on it if it doesn't work.
    • If you can't get UTM or Virtual Box to install or to use the .iso file to install Linux, continue to the next prepare assignment to set up your AWS Account in the cloud
    • You will use the AWS or RedHat Linux systems instead for your assignments.
  3. Sign in to the RedHat Academy.
  4. In the RedHat Academy, click on the Getting Started with Linux Fundamentals course and then click on the "Lab Environment" tab.
  5. Click on the "Start Lab" button to launch the lab environment.
  6. Once the lab environment is launched, you will have access to a virtual machine running RedHat Linux. You can use this virtual machine to complete your assignments and practice Linux commands.
  7. Make sure to take screenshots of your work in the RedHat Academy lab environment to submit as part of your assignments.

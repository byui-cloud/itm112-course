Part 1: Connect to Google Cloud Platform (GCP)

Login with your @byui.edu email if you are not already logged in.

Click on the "Activate Cloud Shell" button (top right of the screen) to open a terminal window.


From the terminal, launch a simple node express app as a container by running this command:

docker run -d --name bb -p8080:8080 blaineh7/bb:1.0

Click on the "Web Preview" button (above the terminal) and click "Preview on Port 8080" and see the Bulletin Board Website

Part 2: Add Your Name to Bulletin Board Website

Back at the terminal, you can edit the index.html file within the container. To connect to the Linux Shell of the docker container/image, type (this starts an interactive terminal {-it} bash script and bb is the name of the container):

docker exec -it bb bash

To use a text editor in the Linux shell of the image/container, update the linux packages to then install VIM:

apt update
apt install vim

'apt' is the package manager for Debian-based Linux distributions to install packages/apps/software on this distro, but in other distros, you might use 'dnf' (like you might have seen in RedHat videos) or 'yum' to install a package.

Edit the index.html webpage of the Bulletin Board using VIM(VI):

vi index.html

Modify line 20 "Welcome to the Bulletin Board" to be:

"Welcome to {enter your name here}'s Bulletin Board"

Substituting your name in place of {enter your name here}

  • #Now you are using VIM or VI text editor. To edit the file:
  • Type "i" to go into insert mode, which allows you to add text:
    • Press the 'i' key to enter insert mode.

    Press the arrow keys on your keboard to move to line 20

    Type yourname (put your actual name: ex: Bob Jones)

    To exit "insert" mode in VIM, hit ESC on your keyboard.

    Type ":wq". That will save (write) and quit.

  • If you have problems and need to save without quitting, type: ESC and then ":q!".

To get out of the bash shell inside your image/container, type "exit" and press the "etner" key on your keyboard.

To see the changes you made to the index.html file, click on the "Web Preview" button (above the terminal) and click "Preview on Port 8080" and see the Bulletin Board Website

Practice a 'ping' to confirm the network is working (8.8.8.8 is Google's DNS server):

ping 4 8.8.8.8

Practice a 'traceroute' to see the path packets take to reach a destination:

traceroute 8.8.8.8

Practice a 'nslookup' to see the IP address of a domain name (you could put 8.8.8.8 instead too):

nslookup google.com

Check your network configuration (or short form 'ip a'):

ip addr show
